첫 설치 카페는 **문큐(문화인큐베이터)** — 서울대 학생회관(63동) 437호, 학생 자치 문화단체가 운영하는
카페. **앱의 카페 id 는 `moonq`** (2026-10-13 서버에서 확인. snu-101 아니다). 공간 소유자가 서울대라서 문큐 운영진 동의와 별도로 **학교 허가**가
필요하다 (2026-09-14 사용자가 확인).

- 1차 창구: **학생지원과** (학생회관·중앙동아리·학생 자치단체 담당) — student@snu.ac.kr,
  02-880-5052 / 중앙동아리 담당 02-880-5565. 행정관(60동) 3층.
- CCTV(영상정보처리기기) 총괄: **캠퍼스관리과** 02-880-5130 (학교 공개 방침 페이지 기준, 이메일 비공개).
- 2026-09-14 문의 메일 초안을 만들어 줬다 (scratchpad, 세션마다 사라지니 보냈는지 사용자에게 확인).

**Why:** 허가 없이 달면 철거·분쟁 위험. 메일 내용(영상 미저장, 카페 안만 촬영)이 실제 박스 동작과
어긋나면 안 된다 — 이름표 사진 1장은 서버에 올라간다.

**How to apply:** 학교 답장이 오면 그 조건(안내문 게시·심의 등)을 `카페설치당일.md` 에 반영한다.
관련: [[cafe-install-day-protocol]], [[supabase-publish-state]].


**2026-10-13 사용자가 알려준 매장 정보:**
- 주소: **서울 관악구 관악로 1** 학생회관 63동 **437호**
- 영업: **11:00 시작 · 주문 마감 17:00 · 영업 마감 17:30**
- 그래서 **설치는 아침 8:00~11:00 이 가장 좋다** — 손님이 없어야 좌석을 그리기 쉽고,
  11:00 영업이 시작되면 그대로 남아 손님이 앉은 자리로 판정을 대조할 수 있다.
- 서울대 문의 메일 초안은 이제 저장소에 있다: `문서/4_대외/서울대_공간사용_문의메일.md`
  (scratchpad 가 아니다). **"정지 사진 1장은 남긴다"는 문장은 지웠다** — 사진 업로드
  경로를 2026-09-11 에 코드째 없앴으므로 학교에 보내면 거짓이 될 문장이었다.
