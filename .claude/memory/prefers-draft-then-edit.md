사람이 손으로 하는 단계를 설계할 때, **백지에서 그리게 하지 말고 자동으로 만든
초안을 먼저 올려놓고 고치게 한다.** 2026-09-01 2D 평면도 설계에서 사용자가
직접 말했다: *"빈 화면에 그리라고 하면 너무 백지라서 감이 안 오잖."*

**Why:** 이 저장소가 이미 `calibrate.py --preseed`로 같은 패턴을 쓰고 있고
(모델이 잡아준 것을 사람이 지우고 더하기), CLAUDE.md가 허용한 수작업 범위도
"잘못 잡힌 것 지우기 + 못 잡은 것 추가하기"로 정의되어 있다. 백지 작업은 그
범위를 넘고, 설치 현장에서 실제로 안 끝난다.

**How to apply:** 사람 손이 필요한 새 기능을 설계할 때 "자동으로 어디까지
깔아줄 수 있나"를 먼저 답하고, 그 다음에 "사람이 무엇을 고치나"를 정한다.
자동 초안이 근사라서 틀릴 수 있다는 점은 숨기지 말고, 그게 사람이 고치는
단계가 필수인 이유로 설명한다. 관련: [[judgement-units-vs-evidence]]
