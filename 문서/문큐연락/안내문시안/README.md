# 출입문 안내문 시안 — 원본 파일

`*.dc.html` 과 `canvas.json` 이 원본이다. 이걸 고쳐서 캔버스를 다시 만든다.

| 파일 | 내용 |
|---|---|
| `Main.dc.html` | **확정안.** 손님에게 말 거는 안내문 + 좌석 배치도 (A5 세로) |
| `OptionB.dc.html` | 함께 붙일 표준 안내판 (A5 가로) |
| `OptionA.dc.html` | 안 고른 시안 (A5 세로) |
| `Sticker.dc.html` | 유리문 스티커 (지름 150mm) |
| `canvas.json` | 캔버스 배치·쪽 나눔·메모 |

`moonq-door-notice.html` 은 **빌드 결과물이라 저장소에 안 넣는다** (2.4MB — 편집기가
통째로 박혀 있다). 클로드 코드에서 `/design` 으로 다시 만들면 된다.

올라가 있는 캔버스: https://claude.ai/code/artifact/fb704f72-d2d9-46b9-8f31-49a6ada29e24

## 아직 안 맞는 것

확정안에 "영상을 즉시 지운다" 고 적혀 있는데, 영상은 정말 안 남지만
**판정 기록은 남는다** (`문서/판정개선_데이터설계.md`). 규제 샌드박스 신청서에
뭐라고 썼는지 확인한 뒤 문구를 맞춰야 한다.

그림의 좌석 배치는 **문큐의 실제 배치가 아니다.** 그래서 범례 옆에
"그림은 예시입니다" 를 넣어 뒀다. 설치 당일 실제 배치를 보고 다시 그린 뒤 그 줄을 뺀다.
