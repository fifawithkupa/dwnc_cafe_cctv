# 문큐 — 연락과 안내문

**섭외는 끝났다.** 문큐가 첫 설치 매장으로 정해졌고 앱의 카페 id 는 `moonq` 다.
처음 연락할 때 쓴 글 세 개(인스타 디엠·문자·메일)는 역할이 끝나 2026-10-13 에 지웠다.
필요하면 `git log --diff-filter=D -- 문서/문큐연락/` 로 찾는다.

## 남은 것 — 출입문 안내문

`안내문시안/` 은 설치 당일 **카페 입구에 붙일 촬영 안내문**이다. C안으로 확정했다.
개인정보 보호법상 영상을 찍는 곳에는 안내가 있어야 하고, 우리는 영상을 저장하지
않지만 **찍는다는 사실 자체는 알려야 한다.**

## 말할 때 지키는 것 (매장·학교 상대로 그대로 유효)

- **"CCTV" 라는 말을 쓰지 않는다.** 대신 "영상을 보고 빈자리를 센다"고 정확히 말한다.
  영상을 본다는 사실을 먼저 말하고, 저장하지 않는다는 점을 바로 이어 붙인다.
  숨기면 신뢰를 잃는다.
- **비용은 전부 우리가 부담한다.** 매장이 내주는 것은 공유기(와이파이)와 설치 당일
  좌석 확인 한 번뿐이다.
- **사진도 서버로 보내지 않는다** (2026-09-11 에 그 경로를 코드째 지웠다).
  매장 배치 사진이 필요하면 사람이 폰으로 찍어 메신저로 준다.
