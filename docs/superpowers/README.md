# 지난 설계서·계획서 보관소

여기 있는 글은 **그 기능을 만들던 때의 기록**이다. 날짜가 파일 이름에 있고,
그 날짜 기준의 사실이 적혀 있다 — 테스트 개수, 당시 점수, 당시 파일 구조 같은 것은
지금과 다르다.

**지금 사실을 알고 싶으면 여기를 보지 말고 아래를 본다:**

| 알고 싶은 것 | 어디 |
|---|---|
| 지금 코드가 하는 일 | 저장소 맨 위 `README.md` |
| 왜 이렇게 되어 있나, 결정 기록 | `문서/SEATNOW_전체정리.md` |
| 남은 할 일 | `문서/plan.md` |
