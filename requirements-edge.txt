# 엣지 박스 전용 설치 목록 — 리눅스 · GPU 없음
#
# 왜 따로 있나
#   문서 4단계는 "엣지에서도 accepted=70 이 나오는가"로 합격을 판정한다.
#   그러려면 노트북과 **같은 라이브러리**가 깔려야 한다. requirements.txt 는
#   큰 것 네 개만 고정하기 때문에, 나머지는 설치하는 날짜에 따라 달라지고
#   그러면 70칸이 나와도 우연인지 확인인지 알 수 없다.
#   이 파일은 70칸을 낸 노트북(2026-09-03, Python 3.11.9)의 실제 설치 목록이다.
#
# 파이썬 버전
#   박스에 깔려 있는 것을 그대로 쓴다. 우분투 22.04 는 3.10, 24.04 는 3.12 이고
#   아래 목록은 **셋 다(3.10/3.11/3.12) 설치된다** — 필요한 파일이 다 있는 것을
#   확인했다. 우분투에 3.11 을 따로 넣으려 하지 말 것 (22.04 저장소의 python3.11
#   은 정식판이 아니라 rc 다).
#   노트북은 3.11.9 다. 판정이 노트북과 다르게 나오면 그때 이 차이를 의심한다.
#
# torch 는 반드시 CPU 판이어야 한다
#   그냥 pip install 하면 리눅스에서는 **엔비디아 GPU용(CUDA) 판**이 받아진다.
#   이 박스에는 GPU가 없어서 한 번도 안 쓰이는데 디스크만 2~3GB 더 먹는다
#   (문서가 요구하는 여유가 10GB다). 아래 --index-url 두 줄이 그걸 막는다.
#
# 설치
#   ./venv/bin/python -m pip install -r requirements-edge.txt
#
# 확인 — torch 버전 끝에 +cpu 가 붙어 있어야 한다
#   ./venv/bin/python -c "import torch; print(torch.__version__)"
#   → 2.2.2+cpu
