# 앱 연동 — Supabase 에서 좌석 상태 읽기

> 대상: 손님 앱 개발자. 박스가 15초마다 쓰는 값을 어떻게 읽고, 어떻게 보여줘야 손님이
> 틀린 정보를 안 받는지 적었다. 표를 만드는 SQL 은 `deploy/supabase/schema.sql`.
> 설계 배경은 `docs/superpowers/specs/2026-09-08-supabase-publish-design.md`.

## 규칙 세 개 — 이것만은 꼭

1. **45초 규칙.** `cafe_live.updated_at` 이 지금보다 **45초 이상** 오래됐으면 숫자와 지도를
   "확인 중"으로 바꾼다. `status = 'gap'` 이어도 같다. 박스가 꺼지거나 카페 인터넷이 끊기면
   마지막 값이 그 자리에 영원히 남는다. 그대로 보여주면 손님이 어제 값을 보고 카페에 온다.
2. **빈 자리는 `free_tables` 만 쓴다.** `total_tables - occupied_tables` 로 계산하지 않는다.
   그 차이에는 "모름"이 섞여 있고, 모름을 빈 자리로 보여주면 손님을 남의 자리로 보낸다.
3. **지도 칸은 `seat_id` 로 짝짓는다.** `cafe_maps.floorplan.seats[].seat_id` 와
   `cafe_live.seats[].seat_id` 가 같은 값이다. `cafe_live` 에 없는 칸(카메라 화각 밖)은
   회색 "확인 불가"로 그린다.

## 표

### `cafes` — 카페 목록

| 열 | 뜻 |
|---|---|
| `id` | 짧은 문자열 키. 다른 두 표의 `cafe_id` |
| `name`, `address` | 표시용 |

### `cafe_live` — 카페당 한 줄, 15초마다 바뀐다

| 열 | 뜻 |
|---|---|
| `status` | `live` 정상 / `gap` 카메라 끊김 (모든 자리 unknown) |
| `total_tables` | 전체. **테이블 기준** — 바 자리는 칸 하나가 1 |
| `occupied_tables` | 사용중 |
| `free_tables` | **확실히** 빈 것 |
| `unknown_tables` | 모름 (보이긴 하는데 사람이 앉은 건지 판단이 안 되는 상태) |
| `seats` | 아래 JSON |
| `tick_at` | 박스가 판정한 시각 (박스 시계 — 참고용) |
| `updated_at` | **서버 시계.** 45초 규칙은 이걸로 잰다 |
| `box_version` | 박스 코드 버전. 값이 이상할 때 추적용 |
| `schema_version` | 지금 1. 바뀌면 이 문서도 같이 바뀐다 |

`seats`:

```json
[
  {"seat_id": "T1",     "kind": "table",    "zone": null,   "state": "occupied", "reason_code": null},
  {"seat_id": "T2",     "kind": "table",    "zone": null,   "state": "empty",    "reason_code": null},
  {"seat_id": "BAR7-1", "kind": "bar_seat", "zone": "BAR7", "state": "unknown",  "reason_code": "occluded_lower_body"}
]
```

- `state` 는 `occupied` / `empty` / `unknown` 셋뿐이다. 애매한 것을 빈 자리로 반올림하지 않는다.
- `reason_code` 는 `unknown` 일 때만 값이 있다. 앱은 안 보여줘도 된다 (우리 개발용 코드다).
- `kind = "bar_seat"` 는 창가 바처럼 한 명씩 앉는 칸이다. `zone` 이 같은 칸끼리 묶으면
  "바 6칸 중 2칸 사용중" 처럼 보여줄 수 있다.
- 카메라 화각 밖이라 판정하지 않는 자리는 이 목록에 **없다.**

**목록 화면 문구 제안:** `사용중 {occupied_tables} / 전체 {total_tables}`, 옆에 작게
`모름 {unknown_tables}` (0 이면 생략). "빈 테이블 N개"를 쓰려면 `free_tables` 를 쓴다.

### `cafe_maps` — 카페당 한 줄, 지도

| 열 | 뜻 |
|---|---|
| `floorplan` | 아래 JSON |
| `version` | 지도가 바뀔 때마다 올라간다. 값이 달라졌을 때만 다시 받으면 된다 |
| `updated_at` | 서버 시계 |

```json
{
  "schema_version": 2,
  "extent": {"width": 1000, "height": 562},
  "seats": [
    {"seat_id": "T1", "kind": "table", "x": 358.9, "y": 482.1, "w": 150, "h": 105,
     "angle": 0, "shape": "rect", "needs_review": true, "image_anchor": [1145.4, 556.7]}
  ],
  "chairs": [
    {"seat_id": "T1", "x": 300.0, "y": 470.0, "w": 46, "h": 46, "angle": 0,
     "capacity": 1, "hidden": false, "needs_review": true, "image_anchor": [1131.5, 564.9]}
  ],
  "landmarks": [
    {"kind": "door", "label": "입구", "x": 20, "y": 500, "w": 80, "h": 20, "angle": 0}
  ],
  "counters": [],
  "walls": [[0, 0], [1000, 0], [1000, 562], [0, 562]]
}
```

- 좌표는 미터가 아니라 그림 단위다. `extent` 를 화면 크기에 비율대로 맞춘다.
- `seats[].x, y` 는 칸의 **왼쪽 위**, `w, h` 는 크기, `angle` 은 시계 방향 회전(도),
  `shape` 는 `rect` 또는 `round`. `kind` 가 `counted_zone` 이면 바 칸이다.
- `chairs[].seat_id` 는 그 의자가 속한 자리. `hidden: true` 면 그리지 않는다.
  `capacity` 는 앉을 수 있는 사람 수 (2인 벤치는 2).
- `landmarks[].kind` 는 `wall` `door` `counter` `window` `sofa` 중 하나.
  `walls` 는 벽 꼭짓점 목록. 둘 다 비어 있을 수 있다.
- `image_anchor` 와 `needs_review` 는 우리 편집 도구용이다. 앱은 무시한다.

## 읽기 (supabase-js)

```js
const { data: cafes } = await supabase.from('cafes').select('id,name,address');

const { data: live } = await supabase
  .from('cafe_live').select('*').eq('cafe_id', 'dwnc').single();

const stale =
  !live || live.status === 'gap' || Date.now() - new Date(live.updated_at) > 45_000;

const { data: map } = await supabase
  .from('cafe_maps').select('floorplan,version').eq('cafe_id', 'dwnc').single();

supabase
  .channel('cafe_live:dwnc')
  .on(
    'postgres_changes',
    { event: '*', schema: 'public', table: 'cafe_live', filter: 'cafe_id=eq.dwnc' },
    (payload) => render(payload.new),
  )
  .subscribe();
```

앱은 **anon 키**만 쓴다. 쓰기는 권한이 없어 거부된다.

## 화면에서 색 고르기

| 상태 | 칸 색 | 문구 |
|---|---|---|
| `occupied` | 진한 색 (차 있음) | 사용중 |
| `empty` | 연한 색 / 빈 테두리 | 비어 있음 |
| `unknown` | 회색 | 모름 |
| `cafe_live` 에 없는 칸 | 아주 연한 회색, 점선 | 확인 불가 |
| 45초 넘음 또는 `gap` | 지도 전체를 흐리게 | 확인 중 |

## 박스 계정 (운영자용)

박스는 Supabase 인증 사용자 하나로 로그인해 자기 카페 줄만 쓴다.

1. Authentication → Add user: `box-<카페id>@seatnow.local`, 비밀번호 정하기, Auto Confirm 켬.
2. `boxes` 표에 한 줄: 그 사용자의 UUID 와 `cafe_id`.
3. 박스의 `deploy/seatnow.env` 에 다섯 값 (`deploy/seatnow.env.example` 참고) 을 넣고
   `systemctl --user restart seatnow`.
4. 켜졌는지 확인: 박스 시작 화면에 `Supabase 전송: 켜짐 (카페id)` 가 찍힌다.
