# angle1 — 사진 한 장씩 확인하기

사진 12장을 시간 순으로 놓았다. **파일 이름만 봐도 무엇을 볼지 알 수 있다.**

```
01_t0000s_점유3빈9모름0_사람3대2_차이+1_★_원본.jpg
   |  |     |              |         |
   |  |     |              |         +-- ★ = 우리와 Codex가 다름
   |  |     |              +-- 우리가 센 사람 : Codex가 센 사람
   |  |     +-- 우리 좌석 판정 (총 12자리)
   |  +-- 영상에서 몇 초 지점인가
   +-- 순서
```

`_원본`은 아무것도 안 그린 사진, `_판정`은 우리가 판정을 그려 넣은 사진이다.
파일 순서상 원본이 먼저 온다.

### 판정 그림 보는 법

| 그림 | 뜻 |
|---|---|
| **빨간 상자 `X T1`** | 그 자리를 **사용 중**으로 봤다 |
| **초록 상자 `O T3`** | 그 자리를 **빈자리**로 봤다 |
| **회색 상자 `? T5`** | **모름** — 보이긴 하는데 판단이 안 됐다 |
| **파란 상자 `person`** | 우리가 **사람으로 잡은 것** |
| 맨 위 검은 띠 | 그 시점의 합계 (`X used` 사용중 / `O free` 빈자리 / `? unknown` 모름) |

`T1`~`T6`은 테이블, `BAR7-1`~`BAR7-6`은 창가 바 자리다.
**테이블은 통째로 한 자리로 센다** — 4인석에 한 명만 앉아 있어도 그 테이블 전체가 빨강이다.

### 특히 이걸 봐줘

- **파란 상자가 없는 사람이 있는가** — 그게 우리가 놓친 사람이다
  (예: `06_t0035s`의 안쪽 창가에 앉은 사람에게 파란 상자가 없다)
- **사람이 없는 곳에 파란 상자가 있는가** — 헛것을 본 것이다
- **빨간 자리에 정말 사람이나 짐이 있는가**
- **초록 자리가 정말 비어 있는가** — 이게 틀리면 손님을 남의 자리로 보낸다

**원본을 먼저 보고 직접 세어 본 뒤 판정을 보는 것**을 권한다.
답을 먼저 보면 눈이 그쪽으로 끌려간다.

## 무엇을 보면 되나

1. **사람 수가 맞나** — ★ 표시된 장면이 우리와 Codex가 다른 곳이다
2. **빈 테이블을 빈 것으로 봤나** — 아래 표에서 자리별 판정과 이유를 볼 수 있다
3. **짐만 놓인 테이블을 어떻게 봤나** — 테이블은 짐도 점유로 세고, 바 자리는 안 센다

> Codex도 사람이 아니라 기계다. 우리와 다르다고 Codex가 맞는 건 아니다.
> 사진을 보고 **네가 직접** 판단해줘. 그게 이 폴더의 목적이다.
