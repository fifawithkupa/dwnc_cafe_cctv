2026-09-08 집에서 카메라(하이크비전 DS-2CD1143G2-LIU)·PoE 인젝터·엣지 박스 연결 시험을
통과했다. 카메라는 활성화됐고 2026-09-08 저녁에 **DHCP 로 바꿔뒀다** ("카페 가기 전 준비"
완료; 집에서는 192.168.0.40). 카페에서 찾을 때는 박스에서 대역 전체를 ping 으로 훑고
`ip neigh` 에서 MAC 을 찾는다 — 브로드캐스트 핑에는 답하지 않는다. 박스는 `uhho.local`(MAC 64:00:6a:79:d0:a8), 카메라 MAC 8c:22:d2:e4:99:d3.

**Why:** 사용자는 비개발자이고 현장에서 노트북으로 나를 부른다. 저장소의 `카페설치당일.md`
12장에 단계별 호출 문장과 내가 할 일이 적혀 있다. 그 문서가 현장의 계약이다.

**How to apply:** 사용자가 "카페 도착했어. 박스 찾아줘", "카메라 찾아줘", "지금 카메라 사진
보여줘", "좌석 그리기 시작해줘", "저장했어. 박스에 올려줘", "지금 판정 상태 보여줘",
"오늘 설치 기록 남겨줘", "어제 판정 기록 봐줘" 라고 하면 `카페설치당일.md` 의 해당 절을
읽고 그대로 한다. 카메라 설정은 ISAPI(웹 설정 API)로 curl --digest 로 바꿨다; 주소 변경은
재부팅 필요. 카메라를 다른 대역에서 찾을 때는 박스에 임시 주소를 붙이고(sudo 는 사용자가
별도 PowerShell 창에서 침) `ssh -L` 로 끌어온다. 노트북 네트워크는 절대 안 건드린다
([[never-touch-laptop-network]] — CLAUDE.md 에도 있음).


**2026-10-13 사용자가 정한 설치 순서 (문서도 이렇게 다시 씀):**

1. 카페 가서 **전부 연결한다** (박스·인젝터·카메라, 아직 천장에 안 단다)
2. **연결 확인 3종** — 사용자가 "연결 확인해줘" 라고 부른다. 박스에서
   `python3 -m install.check_install --shot /tmp/shot.jpg` 를 돌려 ① 카메라 연결
   ② 판정이 도나 ③ 서버로 나가나 를 한 번에 보고, 사진도 떠서 보여준다.
   **이게 통과해야 자리 잡기로 간다** — 연결이 안 된 채로 자리를 고르면 헛일이다.
3. 손으로 임시 위치를 잡고 사진을 보며 조정 ("지금 카메라 사진 보여줘" 반복)
4. 고정 → 선 정리 → 좌석 그리기 → 카페 id 를 `moonq` 로 → 가동 확인

도구는 `install/check_install.py` (판정은 전부 순수 함수, 시험 16개). 박스에서 실제로
통과 확인했다 (2026-10-13). 카메라 사진은 ffmpeg 로 한 장 떠서 scp 로 가져와 Read 로 본다.

**화면이 뿌옇게 나오면 돔 커버 안쪽 보호 비닐을 안 뗀 것이다.** 렌즈가 고정 초점이라
아주 가까운 것은 원래 안 맞는다 (설치 높이에서는 문제없다).
