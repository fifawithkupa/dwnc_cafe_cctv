# 문큐 카페 연락 (첫 파일럿 매장 제안)

학교 동아리가 운영하는 교내 카페 "문큐"에 SitNow 시범 설치를 제안하기 위한 글 모음.
아직 실제 카페에 적용한 적이 없어서, 문큐를 첫 파일럿 매장으로 삼는 것이 목표다.

## 순서

1. `2_인스타DM.md` — 첫 연락. 인스타 디엠으로 보낸다. 목적은 **메일 주소를 받는 것**.
2. `3_문자.md` — 디엠에 3~5일 답이 없을 때만. 운영위원장 번호로 **문자**. 전화는 걸지 않는다.
3. `1_메일.md` — 메일 주소를 받은 뒤 보내는 본 제안.

## 말할 때 지키는 것

- **"CCTV" 라는 말을 쓰지 않는다.** 대신 "영상을 보고 빈자리를 센다"고 정확히 말한다.
  영상을 본다는 사실을 먼저 말하고, 저장하지 않는다는 점을 바로 이어 붙인다. 숨기면 신뢰를 잃는다.
- **비용은 전부 우리가 부담한다.** 매장이 내주는 것은 공유기(와이파이)와 설치 당일 좌석 확인 한 번뿐.
- **인터뷰는 10분.** 길게 잡으면 거절당한다.
- 규제 샌드박스 제도에 검토 신청해 둔 상태라는 점을 근거로 쓴다.

## 아직 없는 것

서비스 소개 자료, 설치 예시 사진, 출입구 안내문 문구는 **아직 만들지 않았다.**
그래서 세 글 어디에도 "자료를 보내드리겠다"는 약속을 넣지 않았다.
상대가 요청하면 그때 만든다.
