# 사람 대조 (Codex 판독 검증용)

Codex 판독을 믿어도 되는지 가리는 대조군이다. 여기가 어긋나면 Codex 판독
전체를 폐기하고 판독표의 `실제` 칸은 사람이 손으로 채운다 (설계 §5-3).

## ⚠ 이 표는 **분석을 실행하지 않은 사람**이 채워야 한다

`seatnow.py`는 tick마다 판정 결과를 화면에 찍는다.

```
[ 30.0s] tables=4 occupied=3 empty=1 ... poses(seated/standing/unknown)=1/1/0
```

`poses`의 합이 곧 **코드가 찾은 사람 수**다. 즉 사진을 뽑은 사람은 이미
30개 tick 전부의 답을 본 상태이고, 그 상태로 세면 앵커링된다 (설계 §5-4).

**세는 법**: 아래 사진을 하나씩 열어 보이는 사람 수를 센다. JSONL과
`frames/*/marked/` 는 **다 세기 전까지 열지 않는다.**

## 이미 오염된 항목 (참고용, 대조에 쓰지 말 것)

| 사진 | 사람 수 | 앉음 | 섬 | 센 사람 | 메모 |
|---|---:|---:|---:|---|---|
| `frames/angle1/clean/t0015.0s.jpg` | 2 | 0 | 2 | Claude (오염) | 창가 카운터에 등 돌리고 선 흰옷 1명, 오른쪽 창가에서 의자 쪽으로 몸을 굽힌 검은옷 1명. **셀 때 이미 코드의 `poses=1/1/0`을 본 뒤였다** |

> 참고로 Codex는 같은 사진을 독립적으로 **2명 / 앉음 0 / 섬 2**로 읽었다.
> 코드는 **앉음 1 / 섬 1**로 봤다. Codex는 코드 답을 본 적이 없으므로
> 이 불일치는 오염과 무관하게 유효하다.
