# 문서

코드만 봐서는 알 수 없는 것들. **절차 · 할 일 · 정리**를 여기 모은다.

루트에는 `README.md` 와 `CLAUDE.md` 둘만 둔다. 앞의 것은 깃허브 첫 화면이고,
뒤의 것은 클로드 코드가 루트에서 읽는 운영 전제다.
기술 문서(설치 12단계, 지난 계획서)는 `docs/` 에 있다.

## 박스에는 안 내려간다

이 폴더는 엣지 박스에 풀리지 않는다 (`문서/박스업데이트.md` 4절).
박스에서 도는 것만 박스에 두기 위해서다. 필요하면 `git show HEAD:문서/plan.md` 로 읽는다.
