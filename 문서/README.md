코드만 봐서는 알 수 없는 것들을 여기 모은다. **네 묶음**으로 나눴다 (2026-10-14).

| 폴더 | 무엇이 들어 있나 | 언제 여나 |
|---|---|---|
| `1_지금할일/` | 지금 어디까지 왔고 다음에 뭘 하나 | **매번 여기부터** |
| `2_절차/` | 그대로 따라 하는 순서 | 현장에 가거나 박스를 만질 때 |

루트에는 `README.md` 와 `CLAUDE.md` 둘만 둔다. 앞의 것은 깃허브 첫 화면이고,
뒤의 것은 클로드 코드가 루트에서 읽는 운영 전제다.
박스를 처음 만드는 기술 문서는 `../docs/` 에 있다.

## 박스에는 안 내려간다

이 폴더는 엣지 박스에 풀리지 않는다 (`2_절차/박스업데이트.md` 4절).
박스에서 도는 것만 박스에 두기 위해서다. 필요하면 `git show HEAD:문서/1_지금할일/plan.md` 로 읽는다.
