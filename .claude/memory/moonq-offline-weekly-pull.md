2026-10-14 문큐(moonq) 설치 완료 상태: 카페 공유기(ipTIME 192.168.0.1)는 **바깥 인터넷이 안 들어온다**
(공유기가 "나갈 길 없음" 응답). 사용자는 당분간 운영이 아니라 **시험**이 목적이라고 정했다.

- 박스 192.168.0.2, 카메라 192.168.0.4 (DHCP — 공유기 재부팅 시 바뀔 수 있음, 주소 예약 안 함)
- 박스 설정: 좌석 layouts/moonq.json(테이블 6·의자 21·바 6석), 카페 id moonq, 보관 30일
- 서버 boxes 줄도 2026-10-14 moonq 로 바꿨다 — 인터넷만 들어오면 앱 전송이 바로 시작된다
- 박스 시계가 약 23시간 26분 늦다 (NTP 못 맞춤). 받아올 때마다 pulled.json 에 차이 기록
- ssh: known_hosts 의 192.168.0.2 키가 다른 기기라 `-o HostKeyAlias=uhho.local` 로 붙는다
- 사용자가 "데이터 받아와줘" 하면 `python -m edge.pull_box_logs --host 192.168.0.2` →
  results/box_pull/moonq/ (gitignore). 같이 박스 판정이 도는지(journalctl) 보고한다.

**Why:** 인터넷이 없어 원격 확인이 불가능하다 — 주 1회 방문이 유일한 확인 창구다.
**How to apply:** 방문 때 카메라 주소가 바뀌었으면 박스 설정 SEATNOW_URL 을 고친다
([[cafe-install-day-protocol]]). 사진은 받지 않는다 — 계산값만.
